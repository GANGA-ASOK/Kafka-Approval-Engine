# Kafka Approval Engine (RELAY)

RELAY is an event-driven approval platform: FastAPI + Kafka + MongoDB + Redis backend with a React/Vite frontend.

The project lives in [`relay/`](relay/). Start with the developer guide: **[relay/README.md](relay/README.md)**
(architecture, quickstart, workflow config, RBAC, demo accounts).

Quick start:

```bash
cd relay
docker compose up -d
```
